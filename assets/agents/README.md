# Agent marks

NotifyHub uses its own mark as a watermark in the settings window. The agent marks in the README and local settings identify the respective integrations and belong to their owners.

- **Codex** uses the product icon from the [official Codex page](https://openai.com/codex/).
- **Antigravity** uses the full-color icon from the [Google Antigravity press kit](https://antigravity.google/press).
- **DeepSeek Harness** uses the desktop app icon distributed with [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness).
- **Claude Code** uses the Claude icon from the [official product page](https://claude.com/product/claude-code).
- **Command Code** uses the website icon from [Command Code](https://commandcode.ai/).
